# Algorithm Studies with Python

This repository showcases my studies in algorithms, focusing on fundamental concepts and techniques implemented in Python. Below is a brief overview of the algorithms and data structures explored:

- **Binary Search** 🔍: Implemented both iteratively and recursively to efficiently find an element in a sorted list with O(log n) time complexity.
- **Selection Sort** 📊: A simple O(n²) sorting algorithm that repeatedly selects the smallest element from the unsorted portion of the list.
- **Quicksort** ⚡: A divide-and-conquer sorting algorithm with an average time complexity of O(n log n), using a pivot to partition the list.
- **Recursion** 🔄: Demonstrated through functions like factorial, list counting, and maximum number finding, emphasizing recursive problem-solving.
- **Graph Algorithms** 🌐: Explored breadth-first search (BFS) for finding a mango seller in a social network and Dijkstra’s algorithm for shortest path calculations.
- **Greedy Algorithms** 🎯: Implemented a set cover problem to select radio stations covering specific states, optimizing for minimal stations.
- **Dynamic Programming** 📈: Applied to longest common subsequence problems, showcasing table-based solutions for string comparisons.
- **Data Structures** 🗃️: Utilized hash tables (dictionaries) for caching, voting systems, and key-value mappings, as well as deques for queue-based graph traversal.

The code examples highlight my understanding of algorithmic efficiency, recursion, and problem-solving strategies, with a focus on clean, typed Python implementations. 🐍

Feel free to explore the code for detailed implementations! 😄
